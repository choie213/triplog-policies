TRIPLOG 개인정보처리방침

적용 상태: v12 적용 중

시행일: 2026년 10월 25일 (TRIPLOG v12 운영 배포일)

최종 검토일: 2026년 10월 25일

1. 적용 범위와 운영 주체

TRIPLOG은 앱 소유자 한 명이 사용하는 개인 여행 플래너입니다. 운영 주체는 TRIPLOG 앱의 개인 운영자입니다. 일반인을 대상으로 회원가입을 받거나 여행을 공개하는 서비스가 아닙니다.

이 정책 문서는 누구나 열람할 수 있지만, 문서 공개로 여행 일정·계정·저장 데이터에 대한 접근 권한이 부여되지는 않습니다. 앱과 데이터 API의 소유자 전용 접근 제한은 별도로 유지합니다.

2. 처리하는 정보와 목적

로그인 제공자가 전달하는 계정 식별자·이메일 및 제공되는 경우 이름을 로그인 확인과 소유자 접근 제어에 사용합니다. 여행 데이터는 소유자 식별자와 연결해 저장합니다. 앱이 계정 비밀번호나 결제수단을 입력받지는 않습니다.

사용자가 입력하거나 가져와 저장한 여행명·기간·여행지·일정·방문 순서·시각·메모·주소·수동 좌표·항공편·저장 장소·완료 상태·가져오기 원본 텍스트 또는 JSON과 검토 정보를 여행 관리에 사용합니다. 저장 충돌 방지와 변경 확인을 위해 버전·이전 기록·변경 제안을 관리합니다.

소유자가 ChatGPT에 연결한 MCP 기능을 사용할 때는 소유자의 요청에 따라 여행을 조회하거나 변경을 제안하고, 명시적으로 승인한 변경을 저장할 수 있습니다. 이 연결이 여행의 일반 공개나 친구 공유를 허용하지는 않습니다.

3. 보관·변경·삭제

여행과 관련 기록은 기존 Sites의 D1 저장소에 보관합니다. 사용자가 일정을 수정하면 이전 버전과 변경 제안이 별도로 남을 수 있습니다. 변경 제안의 유효기간 종료는 저장소에서의 즉시 물리 삭제를 의미하지 않습니다.

소유자는 앱에서 여행을 조회·수정·백업·삭제할 수 있습니다. 앱의 여행 삭제 기능은 해당 여행과 연결된 변경 이력·제안을 함께 삭제합니다. 호스팅 제공자의 백업·운영 로그 등의 보관은 해당 제공자의 정책에 따르며, 앱 화면에서의 삭제가 모든 제공자 백업의 즉시 삭제를 뜻하지는 않습니다.

4. Google Maps 및 Places

Google 지도 기능을 사용하는 경우 IP 주소·브라우저 정보·사이트 출처·조회 지도 영역 등 요청 처리에 필요한 정보가 Google에 전달될 수 있습니다. 장소 검색 버튼을 누르면 입력한 장소명·주소와 검색 지역 정보가 Google에 전달됩니다. 앱은 기기의 현재 위치 권한을 요청하지 않습니다.

검색 후보가 여러 개이면 사용자가 실제 주소와 지도 위치를 확인한 뒤 선택합니다. 선택만으로 서버에 저장되지 않으며, 일정 저장이 성공해야 장소 연결이 확정됩니다. Google Place ID와 확인 시각을 여행에 연결하고, 원래 장소명·시각·메모를 검색 결과로 덮어쓰지 않습니다.

Google에서 받은 장소명과 주소는 검색 화면에서 후보를 확인하는 동안만 사용하며, 검색 화면을 닫거나 선택을 확정한 뒤 재사용 캐시에 보관하지 않습니다. 확인한 위치의 좌표와 필요한 출처 정보는 실행 중 메모리에서만 임시 재사용합니다. 재사용 유효기간은 1시간이며 조회·앱 복귀 시 만료 여부를 확인합니다. 앱은 Google에서 받은 이름·주소·좌표를 여행 저장 본문·변경 이력·브라우저 영속 저장소·서비스 워커 캐시에 저장하지 않습니다. 사용자가 직접 입력한 좌표는 여행 데이터로 저장될 수 있습니다.

Google의 정보 처리에는 Google 개인정보처리방침이 적용됩니다. 지도 사용에는 Google 서비스 약관과 Google Maps/Google Earth 추가 서비스 약관도 적용됩니다.

5. 날씨 및 도시 검색

날씨에는 Open-Meteo, 도시 검색에는 Open-Meteo의 GeoNames 기반 데이터를 사용합니다. 도시 검색어·선택 좌표와 API 요청에 필요한 기술 정보가 해당 제공자에게 전달될 수 있습니다. 날짜별 예보와 도시 검색 결과에는 캐시가 적용될 수 있습니다.

관련 안내: Open-Meteo 개인정보처리방침, GeoNames.

6. 로그인·호스팅·기기 저장

ChatGPT 로그인과 Sites 호스팅에는 해당 제공자의 정보 처리 정책이 적용됩니다. OpenAI 개인정보처리방침을 참고하세요.

앱 아이콘과 오프라인 안내 화면 등 정적 리소스를 기기에 캐시할 수 있습니다. 여행 데이터·인증 정보·Google 검색 결과를 서비스 워커의 오프라인 캐시에 저장하지 않습니다. 로그인 세션의 쿠키와 유지 방식은 로그인·호스팅 제공자가 관리합니다.

7. 공개 정책 문서의 호스팅

이 정책과 이용약관의 공개 호스팅에는 앱과 분리된 GitHub Pages를 사용합니다. 두 문서에는 여행·계정 데이터, 데이터 조회 기능, 로그인 기능, Google 지도 SDK, 자체 분석 도구를 포함하지 않습니다.

GitHub Pages는 방문자가 GitHub에 로그인하지 않았더라도 보안 목적으로 방문 IP 주소를 기록·보관합니다. 문서 제공 과정의 정보 처리에는 GitHub 개인정보처리방침이 적용됩니다. 문서에서 외부 제공자 링크를 열면 해당 제공자의 정책이 적용됩니다.

8. 개인용 운영 및 정책 변경

TRIPLOG은 운영자 본인만 사용하는 비공개 개인 여행 플래너이며, 외부 회원가입이나 일반 이용자 대상 서비스를 제공하지 않습니다. 별도의 공개 고객지원 창구를 운영하지 않습니다.

여행 데이터의 조회·수정·삭제는 앱 소유자가 앱에서 직접 관리합니다.

향후 외부 사용자 또는 공유 기능을 제공하거나 개인정보 처리 방식이 변경되는 경우, 적용되는 법적 요구사항을 재검토하고 개인정보처리방침과 시행일을 갱신합니다.
